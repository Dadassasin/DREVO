# ДРЕВО

Генеалогический архив для **Windows 10**, Python 3.12+, Node.js 22.12+. Без Docker. В действующем переносном режиме оригиналы находятся на внешнем диске F:, SQLite и ключ — в папке .drevo рядом с архивом. Программа установлена отдельно на каждом ПК.

Веб-интерфейс: **https://drevo-beta.vercel.app**. API и оригиналы остаются на домашнем компьютере; для работы архива сервер и HTTPS-туннель должны быть включены. Подробности размещения: [Vercel](docs/VERCEL.md).

Для запуска с переключением сайта на текущий ПК используйте `start_online.bat`. Установка второго ПК с внешнего диска и ежедневное переключение описаны в [инструкции для двух ПК](docs/TWO-PCS.md). Автозапуск сервера в Windows отключён.

## Запуск на этом компьютере

1. Запустите `start_server.bat`.
2. Откройте **http://127.0.0.1:8000**.
3. Первоначальный код администратора находится в `.local/INITIAL-ACCESS.txt`. Не публикуйте его. После входа замените код в «Настройках» и удалите этот файл.
4. Откройте «Архив», выберите дело и страницу. Выделите фрагмент инструментом вырезки и добавьте транскрипцию.

Для чистой установки запустите `install.bat`; остановка — `stop_server.bat`. Системные настройки, входящие порты и внешние репозитории установщик не изменяет.

## Возможности

- Reference/managed импорт JPG, PNG, TIFF и ZIP; потоковые хеши, дубликаты, повторный запуск, миниатюры и журнал ошибок.
- Защищённое API, Argon2id, роли viewer/researcher/admin, сессии в памяти браузера, ограничение попыток входа.
- OpenSeadragon: масштаб, перемещение, поворот, полноэкранный режим, выделение в координатах оригинала, сравнение вырезок, отдельные JPG/страница книги/архивный лист.
- Раздельные сущности персоны, упоминания, записи, утверждения, доказательства, транскрипции, связи, задачи, находки и аннотации. Версии и аудит, очередь проверки, FTS5 и поиск похожих кандидатов.
- Подписанные HMAC ссылки со сроком, отзывом и лимитом запросов. По умолчанию выдача запрещена (`private_only`).
- Приватный GitHub JSON-обмен, идемпотентность по UUID, квитанции, конфликты и экспорт контекста.
- Резервирование SQLite Backup API и восстановление с проверкой целостности.

## Проверка разработки

```powershell
cd backend
..\.venv\Scripts\python.exe -m pytest -q
cd ..\frontend
npm ci
npm run build
```

Внешние GitHub/Cloudflare/ChatGPT остаются **unverified** до настоящей сквозной проверки. Публичная публикация и включение передачи архивных копий не выполняются автоматически.

Публичный AI-вход: https://drevo-beta.vercel.app/ai/index.json. [Аудит и фактические ограничения](docs/AUDIT-2026-11-07.md).

Полное руководство владельца: [USER_GUIDE](docs/USER_GUIDE.md). Офлайн-книга на основном диске: F:\Архив\ДОКУМЕНТАЦИЯ ДРЕВО.html.
