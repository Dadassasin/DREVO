# Windows 10: установка и обслуживание

## Установка

Требуются Python 3.12+ x64 с Python Launcher, Node.js 22.12+ и современный Edge/Chrome. Проверенная локальная среда записана в STATUS.md. `install.bat` использует стандартный Windows PowerShell 5.1, создаёт `.venv`, устанавливает фиксированные Python-зависимости, выполняет Alembic и собирает React. Нужен интернет для первоначальной установки пакетов. PowerShell-скрипты сохранены в UTF-8 с BOM для совместимости с Windows 10.

Скопируйте `.env.example` в `.env`, если хотите изменить путь до первого запуска. Установщик делает это при отсутствии `.env`. Путь может содержать кириллицу и пробелы. `.local` должна лежать на локальном диске; SQLite WAL не предназначен для сетевой папки. Доступ к `.local` и `.env` ограничивает `scripts/protect_local.ps1` текущим пользователем и SYSTEM.

## Управление

`start_server.bat` запускает API на `127.0.0.1:8000` и синхронизатор в скрытых процессах. Логи — `.local/server-error.log` и `.local/sync-error.log`. HTTP access log отключён, чтобы токены подписанных ссылок не попадали в журнал. `stop_server.bat` останавливает только проверенные PID процессов этого проекта. В production используйте один процесс Uvicorn; конфигурация рассчитана на домашний сервер.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\check_health.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\register_autostart.ps1
```

Автозапуск настроен при входе текущего пользователя. Для запуска до входа нужен отдельно настроенный Windows task с учётными данными пользователя и правом чтения архива; пароль не встраивается в скрипт. Cloudflared работает отдельной службой (INTEGRATIONS.md). Синхронизатор повторяет соединение с увеличением паузы при ошибках.

## Импорт

В «Импорт архива» выберите разрешённый каталог или ZIP. Корень настраивается только серверным `.env`. Reference не копирует оригиналы. Managed копирует изображения в `.local/managed`, сохраняя исходные файлы. Повторный импорт пропускает неизменённые файлы по размеру и mtime; изменённые пересчитываются. Для принудительной проверки целостности используйте команду verify-integrity.

```powershell
cd backend
..\.venv\Scripts\python.exe -X utf8 -m app.cli import "$env:USERPROFILE\Desktop\Архив"
..\.venv\Scripts\python.exe -X utf8 -m app.cli set-code --role admin
..\.venv\Scripts\python.exe -X utf8 -m app.cli seed-demo
```

Команда seed-demo читает только приватный `demo-seed.json` из каталога данных: массив строк `[id, название, примечание]`. Семейные карточки не входят в публичный код; загруженные карточки требуют проверки и не создают подтверждённых предков или фиктивных сканов. ZIP индексируется без распаковки всего архива; отдельный оригинал извлекается в ограниченный локальный кэш. Чтение сжатого ZIP может требовать повторной декомпрессии, особенно после вытеснения кэша. Запрещены пути `..`, абсолютные имена, symlink-записи, чрезмерные размеры и коэффициенты сжатия. Неисправные изображения попадают в журнал.

После прерывания повторите тот же импорт. База фиксирует результат каждой страницы; на старте сервера не происходит повторной обработки 37 ГБ. Для переименованных каталогов требуется ручная проверка нового дела: идентификаторы страниц включают исходный путь, чтобы не объединять разные копии без решения пользователя.

## Резервирование и восстановление

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\backup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\restore.ps1 -Source "D:\Backup\drevo.sqlite3"
```

Backup API поддерживает согласованную копию во время работы WAL. Рядом сохраняется конфигурация без GitHub token и без ключа подписи. Копию БД храните как секрет: в ней хеши кодов и приватные исторические сведения. Оригиналы резервируйте отдельно; reference не включает их в копию. Для новой установки восстановите пути из `.config.json` вручную, задайте GitHub token заново. Восстановление останавливает процессы, создаёт страховочную копию текущей БД, проверяет integrity_check и отзывает сессии/ссылки. Ключ подписи при необходимости создаётся заново. После восстановления запустите сервер.

## Обновление и ошибки

Перед обновлением сделайте backup. Остановите сервер, обновите исходники, повторите install.bat, запустите start_server.bat. `.env` и данные не перезаписываются.

- «Неверный код»: проверьте роль; восстановите код локальной командой set-code, не редактируйте frontend.
- 429: подождите после неправильных попыток либо завершения обработки изображений.
- Пустой архив: запустите импорт; проверьте `.env` и права Windows на корень.
- Изображение отсутствует: источник переименован/удалён; верните путь или повторите импорт и сопоставьте записи вручную.
- CORS: DREVO_FRONTEND_ORIGIN должен точно совпадать с origin сайта, без пути /DREVO/ и завершающего слеша.
- Синхронизация error: проверьте срок fine-grained token, private репозиторий, ветку main и Contents read/write. Секреты не присылайте в чат.
- JSON 409/conflicted: прочитайте актуальную версию и создайте новое предложение, сохранив исходную.
