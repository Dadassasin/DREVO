# Проверенное состояние

Локальная система для Windows 10 создана и проверена без Docker. Подробный отчёт по реальному семейному архиву хранится только в `.local/STATUS-private.md` и не публикуется.

## Проверки

26 backend-тестов покрывают импорт каталогов и ZIP, дубликаты и повторный запуск, сохранение ID после переноса архива, исключение внутренней папки данных из импорта, защищённые изображения и вырезки, авторизацию и роли, сессии и CORS, подписи и отзыв ссылок, источники и версии, применение исправления человеком, прогресс исследования, календарные даты, FTS5, GitHub mock-обмен и приватность, рестарт и Backup/Restore. Предупреждение Starlette о будущем переходе тестового клиента на httpx2 не мешает успешному завершению.

Edge/Playwright проверяет просмотр, выделение, вырезки, сохранение и проверку транскрипции. Для записи используется отдельная техническая БД; реальные архивные данные не включаются в тестовые артефакты публичного репозитория. React/TypeScript production build, сборка с base `/DREVO/` и разбор скриптов Windows PowerShell 5.1 проходят.

## Внешняя интеграция

Frontend опубликован на **https://drevo-beta.vercel.app** через Vercel CLI на тарифе Hobby. Домашний API доступен через Tailscale Funnel и внешние rewrites Vercel: браузер обращается к тому же домену сайта. В отдельной preview-публикации проверены health, вход, каталог, миниатюра, превью и оригинал; без сессии изображение возвращает 401, неверная подписанная ссылка — 403. Ответы API имеют `private, no-store`, CDN cache MISS. Проверенная конфигурация опубликована в production. Полная исследовательская интеграция с ChatGPT по-прежнему unverified.

На изолированном сервере с явно обозначенными техническими изображениями проверен реальный Cloudflare Quick Tunnel: HTTPS health и подписанный JPEG возвращают 200; приватный каталог без сессии — 401; отсутствие/подделка/отзыв токена — 403; истёкшее разрешение — 410.

Веб-инструмент чата отказался открывать тестовый URL (`URL is not accessible via this tool`). Поэтому полная интеграция **ChatGPT → приватный GitHub → домашний сервер → изображение в ChatGPT → результат → проверка человеком остаётся `unverified`**. Защита ради совместимости не отключалась. Временный тестовый туннель остановлен.

Созданы [DREVO](https://github.com/Dadassasin/DREVO) (PUBLIC) и [DREVO-Research-Data](https://github.com/Dadassasin/DREVO-Research-Data) (PRIVATE). В публичный репозиторий входят только исходники, схемы и документация. Сканы, SQLite, секреты, рабочие сообщения и семейные карточки остаются приватными. Приватный репозиторий получает шаблон JSON-обмена; реальные исследования синхронизируются только после отдельной настройки сервера.

Для повторного развёртывания проверьте настройки [Vercel](VERCEL.md) и [Tailscale](TAILSCALE.md), правильный CORS origin и серверную авторизацию к приватному репозиторию. Перед выдачей копий проверьте архивные права и включите signed_links_allowed только для выбранных дел. Инструкции: INTEGRATIONS.md, CHATGPT.md, ACCEPTANCE.md.

## Ограничения

Просмотрщик использует защищённое превью до 4096 px и вырезки из оригинала; IIIF-пирамида не реализована. Крупные TIFF ограничены по памяти и площади. Исследователь вручную задаёт признак living для чувствительных сведений; свободный текст автоматически не классифицируется. Задача Windows DREVO запускает API при входе пользователя. Funnel сохранён в службе Tailscale. Домашний компьютер и интернет должны работать; крупные сканы расходуют трафик Vercel и пропускную способность Funnel.
