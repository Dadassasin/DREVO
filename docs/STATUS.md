# Проверенное состояние ДРЕВО

Подробный технический отчёт — AUDIT-2026-11-07.md; ежедневная работа — USER_GUIDE.md.

## Работает

- React/Vite frontend на https://drevo-beta.vercel.app.
- FastAPI и SQLite на домашнем Windows-ПК, Tailscale Funnel как HTTPS-вход.
- Основной архив и база на внешнем диске F:, программа отдельно на каждом ПК.
- 145 исторических дел и 39 790 страниц, включая ZIP. Все реальные дела остаются private_only. Для интеграционного теста отдельно создано одно техническое дело и изображение.
- Защищённый просмотр, увеличение, вырезки, роли, сессии, ограничения входа и подписанные ресурсные ссылки.
- Настоящий приватный GitHub request/response/receipt, импорт предложений и идемпотентность.
- Пользователь проверил чтение технического JPG обычным ChatGPT; переданный результат сохранён как proposed через GitHub в SQLite.
- 42 автоматизированных backend/API/script теста, TypeScript/Vite build и реальный браузерный тест прошли.

## Ограничения

Стандартное GitHub-подключение обычного ChatGPT read-only. Автоматическая отправка запросов и результатов из него BLOCKED; ручная передача JSON через пользователя проверена. Это не ошибка серверного worker. Публикация Vercel выполняется CLI; git push сам по себе не запускает её.

Автозапуск Windows отключён. После перезагрузки диск подключается как F: и сайт запускается вручную. Перезагрузка и разрыв сети во время аудита не выполнялись. OCR/HTR всего архива и IIIF-пирамида не реализованы; расширенный/fuzzy-поиск ограничен 5 000 кандидатами. living задаётся вручную, текст автоматически не обезличивается.

## После уборки

Старая конфигурация GitHub Pages удалена, её workflow исключён из текущего кода. Неиспользуемый Cloudflared и старые тестовые публикации удалены. В Vercel сохранены действующая и предыдущая production-версии. Репозитории DREVO и PRIVATE DREVO-Research-Data являются действующими и сохранены.

Копия оригинальных сканов на внутреннем диске оставлена резервной. Свежий аварийный снимок базы, ключа и настроек хранится на внутреннем диске в .local/backups/recovery-current; приватные настройки не входят в публичную документацию. Офлайн-книга со всем руководством и техническими материалами находится в F:\Архив\ДОКУМЕНТАЦИЯ ДРЕВО.html.
