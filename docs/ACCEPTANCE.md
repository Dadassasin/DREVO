# Проверка внешней интеграции

Текущий статус: **unverified**. Этот список выполняется на настоящих GitHub и Cloudflare и в обычном чате ChatGPT. Локальные unit/mock/browser тесты не заменяют его.

| Шаг | Проверка | Требуемый результат |
|---|---|---|
| 1 | Сервер после перезагрузки Windows | health=ok, прежние записи сохранены |
| 2 | GitHub Pages: неверный/верный код | 401 / вход и каталог |
| 3 | JPG без сессии | 401; файлового листинга нет |
| 4 | Приватный GitHub запрос get_pages | responses/pages с исходным UUID |
| 5 | Права дела private_only | выдача ссылки запрещена |
| 6 | Проверенные права + HTTPS | выдаётся временная ссылка на выбранную страницу |
| 7 | HTTPS GET извне | изображение отображается; no-store/no-referrer |
| 8 | Удалить/изменить token | 403 |
| 9 | Истечение TTL | 410 и renew_image_links с новым UUID |
| 10 | Отзыв разрешения | 403 на ранее рабочую ссылку |
| 11 | Изменить ID изображения в URL | 403 |
| 12 | Запрос вырезки | верный фрагмент, исходные пиксели не изменены |
| 13 | ChatGPT читает приватный ответ | получает именно выбранный JPG и срок |
| 14 | ChatGPT реально открывает изображение | описание наблюдаемых деталей соответствует оригиналу |
| 15 | ChatGPT пишет inbox | квитанция, одна новая предложенная запись |
| 16 | Повтор inbox UUID | та же запись без дубликата |
| 17 | Проверка на сайте | статус и аудит меняются, новая версия экспортируется |
| 18 | Backup/restore | целостность ok, прогресс сохранился, прежние сессии отозваны |

На странице «ChatGPT и GitHub» доступны создание тестовой ссылки по page_id, JSON-диагностика протокола, журнал запросов, отзыв и последняя синхронизация. ID страницы копируется из вкладки «Источник». Проверка 14 фиксируется вручную: дата, используемое подключение GitHub, URL без токена, ID страницы, наблюдаемые детали, результат. Полные ссылки с токеном не публикуйте в issue или публичном журнале.

Если веб-инструмент ChatGPT отказывает в GET, сохраните точный тип ошибки и статус unverified. Используется совместимый простой GET `/ai/images/<page_id>?token=...`, возвращающий непосредственно JPEG/PNG/TIFF; для браузеров и инструментов, не поддерживающих TIFF, запросите preview JPEG. Не открывайте весь архив и не отключайте подпись ради обхода ограничения платформы.
