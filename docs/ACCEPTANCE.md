# Проверка готовности

Фактические результаты и границы проверки зафиксированы в AUDIT-2026-11-07.md. Используются Vercel и Tailscale Funnel. Стандартное GitHub-подключение обычного ChatGPT — read-only; ручная передача JSON через пользователя проверена.

| Шаг | Требуемый результат |
|---|---|
| Запуск с подключённым F: | health 200, прежние данные доступны |
| Верный/неверный код | Вход / 401; перебор ограничен |
| JPG и crop без сессии | 401 |
| Реальный GitHub get_pages | responses/pages с исходным UUID |
| private_only без точечного разрешения | Выдача временной ссылки запрещена |
| Разрешённое техническое дело | Подписанный JPG/crop 200 |
| Без подписи/изменённая подпись | 403 |
| Истечение/отзыв/лимит | 410 / 403 / 403 |
| Подмена ID или координат | Другой ресурс/большая вырезка не выдаётся |
| Обычный ChatGPT | Прочитанный случайный код совпадает с картинкой |
| GitHub inbox | Receipt и одна proposed-запись в SQLite |
| Повтор UUID | Прежний результат без дубля |
| Подтверждение человеком | Версия и история сохраняются; AI не подтверждает факт сам |
| Остановка и перенос диска | Запись завершена, внутренняя резервная копия цела |
| После перезагрузки | Ручной start_online.bat, затем тот же health и JPG |

Реальная перезагрузка и разрыв сети в предыдущем аудите не выполнялись. Проверяйте их в удобное время, не прерывая чужой удалённый доступ. Не открывайте всю папку сканов через Funnel, не отключайте подпись ради совместимости. Mock-тесты не заменяют настоящий обмен GitHub и фактическое чтение картинки в ChatGPT. Полные signed URLs не публикуйте в открытых отчётах.
