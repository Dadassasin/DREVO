# Реализованное и оставшиеся ограничения

Действующая система: React/Vite на Vercel, FastAPI/SQLite на Windows, внешний диск F: с архивом и базой, Tailscale Funnel, приватный GitHub exchange. Полный аудит — AUDIT-2026-11-07.md; ежедневные действия — USER_GUIDE.md.

Реализованы reference/managed импорт и ZIP, защищённый просмотр и вырезки, Argon2id и роли, ресурсные HMAC-ссылки, версия/аудит записей, предложения вместо автоматического подтверждения, GitHub-worker, два ПК с переносным диском и переключением сайта, резервирование и офлайн-документация.

Остаются внешние ограничения: стандартный обычный ChatGPT не пишет в GitHub, автоматический git push→Vercel не подключён, сервер после перезагрузки запускается вручную по выбору владельца. OCR/HTR всего архива и IIIF-пирамида не реализованы. Права на распространение конкретных архивных копий проверяет владелец. Новые платные сервисы, Docker, MCP, Render и Cloudflare для работы не требуются.
