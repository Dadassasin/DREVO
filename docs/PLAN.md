# План и границы проверки

1. FastAPI + SQLAlchemy + Alembic + SQLite FTS5. Авторизация Argon2id, непрозрачные bearer-сессии, роли. Сканы читаются только из разрешённого корня.
2. Возобновляемый reference/managed импорт каталогов и ZIP. Потоковые SHA-256, метаданные, контролируемый кэш, защищённые изображения и вырезки.
3. React/TypeScript/Vite, Tailwind, компоненты shadcn, Query, Router, OpenSeadragon. Русские рабочие экраны.
4. JSON-протокол исследований, идемпотентность, версии, проверка и аудит. Приватная GitHub-проекция и отдельный синхронизатор.
5. HMAC-ссылки с отзывом, сроком и лимитами, только после разрешения выдачи копий. Интеграция ChatGPT по умолчанию unverified.
6. Скрипты Windows 10, резервирование SQLite Backup API, восстановление, тесты и инструкции подключения внешних сервисов.

Оригиналы: `%USERPROFILE%\Desktop\Архив`. Никогда не перемещаются и не попадают в Git. Секреты/БД/кэш — `.local/` (исключены из Git). Реальные GitHub Pages / Cloudflare / ChatGPT проверяются отдельно от mock-тестов.
