# Реализованное и оставшиеся ограничения

Действующая система: React/Vite на Vercel, FastAPI/SQLite на Windows, внешний диск F: с архивом и базой, Tailscale Funnel, приватный GitHub exchange. Полный аудит — AUDIT-2026-11-07.md; ежедневные действия — USER_GUIDE.md.

Реализованы reference/managed импорт и ZIP, защищённый просмотр и вырезки, Argon2id и роли, ресурсные HMAC-ссылки, версия/аудит записей, предложения вместо автоматического подтверждения, GitHub-worker, два ПК с переносным диском и переключением сайта, резервирование и офлайн-документация.

Возможности записи ChatGPT зависят от подключения; в пользовательском чате запись файлов проверена. Автоматический git push→Vercel не подключён, сервер после перезагрузки запускается вручную по выбору владельца. OCR/HTR всего архива и IIIF-пирамида не реализованы. Права на распространение конкретных архивных копий проверяет владелец. Новые платные сервисы, Docker, MCP, Render и Cloudflare для работы не требуются.


Уточнение после реального обращения из пользовательского чата: файлы requests/pages и inbox/research-progress действительно появились в приватном GitHub. Категоричный вывод о невозможности записи из любого обычного ChatGPT был неверным: возможности зависят от конкретного подключения. Проверяются фактические файлы и квитанции сервера. Поддерживаются inbox/progress и совместимый inbox/research-progress; исследовательская неопределённость не требует вырезки, если это не прочтение документа. Ссылки интерфейса используют /#/archive/..., а не /archive/.... Пакетный get_pages обрабатывается целиком: одна запрещённая страница блокирует пакет.
