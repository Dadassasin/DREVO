# Работа с внешним архивом на двух ПК

Одна рабочая база находится на внешнем диске рядом с архивом: `F:\Архив\.drevo\drevo.sqlite3`. Папка `.drevo` также содержит ключ подписей, резервные копии и пересоздаваемый кеш. Она исключается из импорта сканов.

На каждом ПК нужны исходники ДРЕВО и собственная установка зависимостей. Виртуальное окружение Python не переносится между компьютерами. На втором ПК до первого запуска установки скопируйте приватный `F:\Архив\.drevo\server.env` в `.env` каталога проекта. Для текущего варианта диск должен иметь букву **F:** на обоих ПК. Не публикуйте `.drevo` или server.env в GitHub.

При завершении работы остановите ДРЕВО через `stop_server.bat`, дождитесь сообщения об остановке, затем безопасно извлеките диск. Скрипт завершает запись SQLite WAL и сохраняет копию внешней базы на внутренний диск в `.local\backups\external-last-stop.sqlite3`. Если скрипт сообщает об ошибке, диск пока не отключайте. Подключите его на другом ПК и запустите ДРЕВО. Работайте только с одной базой на диске; старую базу первого компьютера сохраняйте как резервную, не как отдельную рабочую копию.

При запуске сервер проверяет наличие архива и рабочей базы. Отключение диска во время работы опасно для данных; проверка запуска от этого не защищает.

Перед переносом сохраняйте дополнительную резервную копию базы на внутреннем диске, например:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\backup.ps1 -Destination C:\DrevoBackups\drevo.sqlite3
```

Копия в `.drevo\backups` полезна для отката изменений, но не защищает от потери самого внешнего диска. Домашние сканы и база до переноса остаются резервными копиями.

## Сайт и второй сервер

Перенос базы сам по себе не переключает адрес домашнего сервера. На втором ПК можно работать локально через `http://127.0.0.1:8000`. Для работы через общий сайт Vercel нужно отдельно подключить второй ПК к Tailscale, включить Funnel и обновить три destination в `frontend/vercel.json` на его адрес с повторной публикацией. Обратное переключение требует того же действия. Пока второй сервер не настроен, отключение первого ПК сделает сайт недоступным.

Сначала проверяем локальный запуск второго ПК с внешней базой, затем настраиваем переключение сайта. Идентификационные файлы службы Tailscale между ПК не копируются.
