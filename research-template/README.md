# DREVO-Research-Data — только PRIVATE

Это шаблон отдельного приватного репозитория. Не отправляйте реальные сообщения, контекст, временные ссылки или персональные данные в публичный DREVO.

В новом чате сначала прочитайте manifest.json, затем каталог, актуальные entity_shards и studied_pages. Запросы JSON отправляйте в requests/, результаты — в inbox/. Каждый новый запрос/операция имеет новый UUID. Сервер возвращает ответы в responses/ и квитанции в outbox/receipts/. Читайте схемы schemas/*.schema.json.

Сервер не запускает присланный код, не объединяет людей и не подтверждает родство автоматически. Состояние интеграции unverified до реального открытия изображения средствами ChatGPT.
